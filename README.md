# VT SENTINEL IoT — releases

Firmwares publicados do **VT SENTINEL IoT** (M5Stack CoreInk + sensor ENS210) e o **VT SENTINEL Config**.

- **Configurar ou instalar um aparelho:** abra https://arleyasilva.github.io/vt-sentinel-releases/ no Chrome ou Edge,
  conecte o aparelho no USB e clique em **Conectar aparelho**. O Config pode ser instalado como aplicativo.
- **Versões:** veja a aba [Releases](https://github.com/arleyasilva/vt-sentinel-releases/releases).
  Cada release traz `bootloader.bin` (0x1000), `partitions.bin` (0x8000), `boot_app0.bin` (0xE000),
  `firmware.bin` (0x10000) e `manifest.json` com tamanhos e SHA-256.
- **Atualização (OTA):** o manifesto da versão mais nova fica em
  https://arleyasilva.github.io/vt-sentinel-releases/firmware/manifest.json

Este repositório é gerado automaticamente; o código-fonte é privado.
